Типы ошибок:

Отсутствие перевода

Строка не переведена или содержит значения '#ERROR' или 'Loading...'

Пример: Missing translations: en, ja, zh

Отсутствующий ID

Строка не содержит идентификатор или содержит только символ #

Пример: Missing or invalid ID

Непереведённые символы

Непереведённые одиночные латинские буквы

Пример: Untranslated characters found: I, a

GPT ответы

Ответы от GPT вместо перевода

Пример: The quoted text is empty

Латиница в нелатинских языках

Наличие латинских слов в ja, zh, ko, th, el, bg, uk, ru переводах

Пример: Latin words found: test, hello

Множественный перевод

Несколько вариантов перевода в одной строке

Пример: "What kind is it?" or "Which one?"

Отсутствие ~ в ключе

Ключ перевода не начинается с символа ~

Пример: Key does not start with ~

Отсутствие | в переводе

Перевод не содержит символ |, хотя он есть в ключе (v1.20)

Пример: Missing | separator in translation

Отсутствие тегов

Теги из оригинального текста отсутствуют в переводе

Пример: Missing tags: <i>, </i>

Незакрытые теги

Открытые теги без закрывающего аналога (кроме <br>)

Пример: Unclosed tags: <color>, <b>
